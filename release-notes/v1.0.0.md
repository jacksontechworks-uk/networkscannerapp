## JacksonTechWorks Network Scanner v1.0.0: first release 🎉

This is a portable, self-contained Windows network scanner. There's nothing to install: download the zip, extract it and run `JTW-NetworkScanner.exe`.

### ✅ Working in this release
- **Subnet scan**: detects the local subnet automatically, or scans any other CIDR or range. Uses ICMP, plus ARP to find hosts that drop ping.
- **Totals** of hosts alive and not alive, with live counters.
- **Port scan** with a ~50-port default list that you can edit. **MAC vendor detection** works offline. Includes reverse-DNS names.
- **Filters**: All / Online / Offline, filter by port, and text search.
- **Right-click launchers**: open HTTP/HTTPS in a browser, SSH in a terminal, RDP, SMB shares, FTP, Telnet and VNC.
- **Live Ping** with a latency graph, loss and jitter, **live per-hop route mapping**, and a **world map** for internet targets.
- **Traceroute** and **PathPing** (per-hop loss statistics).
- **LAN Speed Test**: a built-in client/server throughput test, with no iperf needed.
- **Wake-on-LAN**.
- **Export to PDF and CSV** for scans and all diagnostics.
- **Self-update** from GitHub Releases, with SHA-256 verification.
- Modules run in their own windows and keep running in the background when closed. Bring them back from the main window.

### 🚧 Up & coming
Scan profiles, NetBIOS/mDNS discovery, service banners, SNMP, scheduled scans with new-device alerts, device history, ping alerts, multi-stream and UDP speed tests, IPv6, a settings window, and code-signed builds.

### Download
`JTW-NetworkScanner-win-x64.zip` contains the app (Windows 10/11 x64). The `.sha256` file holds its checksum.
